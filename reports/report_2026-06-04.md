### 3. 832 账户 AI 网络威胁一年映射：MITRE ATT&CK 框架缺口

> 来源: Anthropic Frontier Red Team | 2026-06-03

Anthropic 分析 **2025 年 3 月—2026 年 3 月** 间因恶意网络活动封禁的 **832 个账户**（有足够细节做 ATT&CK 映射的子集），部分结果已纳入 **Verizon 2026 DBIR**，完整分析今日发布。

**三大结论**  
1. **AI 使攻击者更危险**：67.3%（560/832）用于 **编写恶意软件**；6.5%（54/832）用于 **横向移动** 等 post-compromise 高复杂度操作——AI 正从「初始访问辅助」转向 **入侵后深度操作**  
2. **威胁等级评估信号失效**：最低技能攻击者平均使用 **~16** 种 ATT&CK 技术，最高技能 **~20**——几乎无相关；Claude Code / API / Chat 界面也与风险等级 **无相关**  
3. **ATT&CK 框架滞后**：2025 年 11 月 disrupted 的国家支持间谍行动使用 **30 技术 / 13 战术**——与 medium-risk actor 相当，但实际 risk score **100/100**；**agentic 自主编排、实时决策、最小人工干预** 尚无 ATT&CK ID

**趋势数据**  
- 前半期 medium+ risk actor 占 **33%** → 后半期 **56%**（**1.7×**）  
- AI 辅助 **账户发现 +8.9%**，AI 辅助 **钓鱼 -8.6%**——攻击重心后移  
- 更高风险 actor 特征：**围绕模型的 scaffolding 架构** 使模型链式执行攻击阶段

**后续行动**  
- 已向最强模型部署 cyber safeguards（恶意软件开发、大规模 exfiltration 检测）  
- 正与 **MITRE** 讨论 ATT&CK 纳入 AI-enabled agentic 行为  
- Frontier Red Team blog 提供 **交互式 ATT&CK 可视化**

**关键观点**: 6/3 Glasswing 扩展 + Trump EO 30 天审查 **同日政策共振** 的数据基础——ATT&CK 若不能描述 **「agent 即攻击者」**，defender 将在 **risk scoring 与 incident response playbook** 两层同时失准。

🔗 [Anthropic 官方报告](https://www.anthropic.com/news/AI-enabled-cyber-threats-mitre-attack)  
🔗 [2025 间谍行动披露](https://www.anthropic.com/news/disrupting-AI-espionage)

### 5. GitHub Copilot App：Agent Merge 与 Issue→Merge 闭环

> 来源: GitHub Blog | 2026-06-02（Build Day 2）

GitHub 发布 **Copilot App**——基于 GitHub 的 **Agent-native 桌面控制中心**，technical preview 向 Copilot Pro / Pro+ / Business / Enterprise 开放。

**核心架构**  
- **My Work 视图**：跨连接 repo 的 active sessions、issues、PRs、后台 automations 一屏可见  
- **Git worktree 隔离**：每个 session 独立 branch 副本，并行 Agent **零 stash / 零 branch 冲突**  
- **Agent Merge**：后台监控 CI、required reviewers、blocking checks；可选自动 fix failing checks 并在条件满足时 **自动 merge**——survive app restart  
- **Canvas（AX 初版）**：双向工作面——plan / PR / browser / terminal / deployment 状态，Agent 更新、人类 edit/reorder/approve

**配套发布**  
- **Cloud + Local Sandboxes** public preview：bounded 执行环境，企业策略集中 enforcement  
- **Copilot Code Review 增强**：medium tier 高推理模型路由、`/security-review` skill、`/rubberduck` GA、Azure DevOps 原生支持  
- **Memory++ / `/chronicle`**：跨 App / CLI / VS Code / GitHub 设备 session 连续性  
- **Partner Agent Apps**：LaunchDarkly、Amplitude、Sonar、PagerDuty、Miro 等可直接 assign issue

**关键观点**: Copilot App 将 GitHub 从 **「代码托管 + PR 审查」** 升级为 **「Agent SDLC 操作系统」**——与 OpenAI Codex Sites、Claude Cowork 形成 **「Issue inbox → 并行 Agent → 自动 merge」** 同质化竞争，**worktree 隔离** 是 multi-agent 并行的工程关键 primitive。

### 8. Microsoft Foundry Toolboxes：统一 MCP 工具 bundle 治理

> 来源: Microsoft Foundry Blog | Build 2026（6/2—3 详述）

**Toolboxes in Foundry** public preview——将 web search、code interpreter、file search、Azure AI Search、MCP servers、OpenAPI tools 等 **打包为单一 MCP-compatible 端点**。

**四支柱 lifecycle**  
1. **Find**：浏览 tool catalog  
2. **Build**：选工具 → 集中配置 auth → 发布 reusable toolbox  
3. **Consume**：任意 MCP client 连一个 URL 获得全部工具  
4. **Govern**：Entra managed identity / OAuth passthrough 集中 credential injection

**兼容 runtime**  
Microsoft Agent Framework、LangGraph、**GitHub Copilot SDK**、Claude Code、自定义 code——**框架无关**。

**版本管理**  
- Consumer endpoint 始终 serve promoted default version  
- Version-specific endpoint 供测试；promote 后 agent **零代码变更** 升级

**Build 2026 同步**  
- **Hosted agents** 预计 7 月初 GA  
- **Routines**（定时 Agent）public preview  
- **Teams / M365 Copilot publishing** 计划 6 月 GA  
- 连接 **Microsoft IQ**（Work IQ / Fabric IQ / Foundry IQ）enterprise data

**关键观点**: Toolboxes 将 Agent 工具层从 **「每个 Agent 重复 wiring + 重复 credential」** 抽象为 **「平台级共享资产 + MCP 标准消费」**——与 OpenAI Codex role plugins、Anthropic MCP connectors 形成 **「工具 bundle 即 infrastructure」** 共识。
