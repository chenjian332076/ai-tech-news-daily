## AI 前沿动态

### 1. OpenAI 模型证伪离散几何 80 年猜想

> 来源: OpenAI | 2026-05-20

OpenAI 宣布其内部通用推理模型在 **Paul Erdős 1946 年提出的平面单位距离问题** 上取得突破：长期以来学界认为「重缩放方网格」构造 essentially 最优，模型却构造出无限族反例，使单位距离对数达到 **n^{1+δ}**（δ>0；后续 Princeton 教授 Will Sawin  refinement 给出 δ=0.014）。证明经 Noga Alon、Tim Gowers、Arul Shankar 等外部数学家审阅并撰写 companion paper；方法将 **代数数论**（无限类域塔、Golod–Shafarevich）引入初等几何，非针对数学定制的 scaffold。这是首次由 AI **自主解决** 某数学子领域中心开放问题；团队亦在 Erdős 问题集上系统评测 test-time compute 与成功率关系。

**关键观点**: 数学成为检验「长链推理 + 跨领域联想」的试金石，也预示 AI 将更深入参与 **AI 研究本身** 的创造性环节。

🔗 [阅读原文](https://openai.com/index/model-disproves-discrete-geometry-conjecture/)  
🔗 [证明 PDF](https://cdn.openai.com/pdf/74c24085-19b0-4534-9c90-465b8e29ad73/unit-distance-proof.pdf)

### 3. 阿里 Qwen3.7-Max：35 小时长程 Agent 与国产榜首

> 来源: 阿里巴巴 / 阿里云峰会 | 2026-05-20

### 4. PopuLoRA：种群共进化破解单 Agent 自博弈坍缩

> 来源: arXiv (Vmax) | 2026-05-16

**PopuLoRA** 在共享冻结 7B 基座上维护 **教师/学生 LoRA 种群**：教师按匹配学生的失败率获奖励（非自评难度），TrueSkill 配对 + 每 10 步 **LoRA 权重空间突变/交叉**（秒级、同秩）作为 PBT 替换步。相对单 Agent Absolute Zero Reasoner 基线，种群在 HumanEval+/MBPP+/LiveCodeBench 与七项数学基准上 **均值全面胜出**，且最弱成员 aggregate 仍超基线。诊断显示单 Agent 会 **自校准** 到「自己能解的简单题」，复杂度指标全线下降；种群则维持 **师生 arms race** 与问题空间覆盖率持续增长。

**关键观点**: RLVR 课程生成的下一 frontier 是 **种群不对称自博弈**，而非更大单个 proposer-solver。

## AI 工程实践

### 5. Pydantic AI v2.0.0b1：Harness-first 与 Capabilities 原语

> 来源: Pydantic | 2026-05-21

**pydantic-ai 2.0.0b1** 从 v1.100.0 分叉，核心转向 **Harness-first**：**Capability** 将 tools、生命周期 hooks、instructions、model settings 打包为单一可组合单元，经 `capabilities=[...]` 贯穿 Agent 各层；核心保持精简，官方 **Pydantic AI Harness** 与第三方能力库分层扩展。破坏性变更包括：裸安装默认更少 extras；`openai:` 默认走 Responses API（`openai-chat:` 保留 Chat Completions）；WebSearch/WebFetch 默认 native-only；默认 instrumentation v5；`end_strategy='graceful'` 时 output tool 成功后仍执行并行 function tools。稳定版预计约两周内发布。

**关键观点**: Python Agent 框架竞争从「Agent 类 API」升级为 **可插拔能力包 + 升级指南驱动的 major 迁移**。

### 6. Google Agent Executor：分布式 Agent 运行时标准

> 来源: Google Cloud | 2026-05-20

Google 开源 **Agent Executor**（基于 [google/ax](https://github.com/google/ax)），面向 **数小时至数天** 的长程 Agent 工作流，原生支持：**持久执行**（事件 log + snapshot 断点续跑）、**安全沙箱隔离**、**单写者会话一致性**、**客户端断线重连与序列回填**、**轨迹分支 checkpoint**（测试不同 agentic 路径）。可与 Antigravity、Managed Agents API、LangChain/LangGraph、ADK、A2A 等混部；强调 **BYO 模型/算力/数据面** 防锁定。同日配套 **Agent Substrate**（与 GKE 合作）：为百万级 sub-second tool call 设计轻量控制面，与 Executor 联调演示已公开，预览版可试用。

**关键观点**: 生产 Agent 的瓶颈正从「模型智商」转向 **可恢复、可分支、可联邦的运行时语义**。

**关键观点**: Agent 工程栈正在补齐 **文档供应链**——与模型能力同等重要的上下文层。

### 9. ChatGPT 敏感对话：跨会话 Safety Summaries

> 来源: OpenAI | 2026-05-14

OpenAI 披露针对 **自杀、自残、伤害他人** 等急性场景的安全升级：模型需识别 **随时间浮现** 的风险信号，而非孤立看待单条消息。创新包括 **Safety Summaries**——由安全专用模型生成、窄范围、限时保留的跨会话事实摘要，仅在罕见高风险时注入上下文；配合训练使 GPT‑5.5 Instant 在 harm-to-others 场景安全响应率 **+52%**，自杀/自残 **+39%**（跨会话评测）。长单会话内自杀/自残 intended safe response **+50%**。摘要平均安全相关性 **4.93/5**、事实性 **4.34/5**；普通对话质量无显著用户偏好差异。与 Trusted Contact、多年心理健康专家网络协同。

**关键观点**: 对话安全从「单轮拒绝」演进为 **时序风险建模 + 最小必要记忆**，为日后生化/网络安全扩展铺路。

## 趋势总结

1. **推理能力外溢到硬科学**：OpenAI 几何证明与 PopuLoRA 的 RLVR 种群机制表明，前沿模型正同时冲击 **纯数学发现** 与 **自生成训练课程** 两条线。

2. **Agent 基础设施标准化**：Google Agent Executor、Pydantic Harness、Ng 的 Context Hub 共同补齐 **运行时、能力组合、文档上下文** 三块拼图，产品竞争进入「栈」层面。

3. **模型发布=Agent 发布**：Gemini 3.5 Flash 与 Qwen3.7-Max 的叙事均围绕 Terminal-Bench、长程工具调用与企业工作流，benchmark 话语从聊天质量转向 **可交付任务时长**。

4. **个人 Agent 产品化**：Gemini Spark 与 ChatGPT 侧的安全时序建模显示，消费级产品开始处理 **24/7 代理 + 长期风险状态** 而不仅是单次问答。

5. **地缘与教育双轨**：OpenAI 国家教育计划与国产 Token 流量优势并存，AI 扩散政策呈现 **「公共品教育」vs「工程化性价比」** 两种国家战略表达。

6. **框架 major 迁移窗口**：Pydantic AI v2 beta 提醒生态用户：Agent 框架已进入 **破坏性升级季**，迁移成本将随 Harness/Capabilities 范式扩散而上升。
