## AI 前沿动态

### 1. Self-Verified Distillation：模型即自己的合成数据流水线

> 来源: arXiv (Tony Lee, Percy Liang) | 2026-05-20

论文 **Self-Verified Distillation** 研究：后训练 LLM 能否在**仅有无标签 seed 问题、无外部教师、无工具反馈**的前提下自我提升？方法让模型对 seed 生成候选解，再经 **三阶段级联自验证**（cycle-consistency → factuality → correctness，每阶段需 judge 一致投票）筛出自策展训练集，并发现「采样更多候选 + 更大验证预算 → 更高质量数据 → 更强模型」。在 **Qwen3-4B** 上，数学（AIME26、HMMT）聚合 pass@1 **+16.7**、科学（GPQA Diamond、HLE）**+11.1**、代码（LCBv5/v6）**+8.3**；0.6B 与 8B 亦有增益。相较仅在测试时多算力的 **UQ-TTC** 基线，多数设定下本方法测试时仅需**单次推理**却更优。

**关键观点**: 自训练的下一代不是「更多合成数据」，而是**可审计的自验证过滤器**——把 UQ 基准的多 validator 思想内化进 post-training 环。

🔗 [论文](https://arxiv.org/abs/2605.26132)

### 2. AlphaProof Nexus：形式化证明 Agent 规模化攻克开放数学问题

> 来源: Google DeepMind / arXiv | 2026-05-21

**AlphaProof Nexus** 将 **Gemini 3.1 Pro** 驱动的证明子 Agent 与 **Lean** 编译器反馈、可选 **AlphaProof** 子目标求解器、以及受 AlphaEvolve 启发的 **Elo 种群进化** 结合。在 **353** 道已形式化的开放 Erdős 问题上，满配 Agent **自主解决 9 道**（含开放 **56 年** 的 #12(i)(ii) 等），另证 **44/492** 道 OEIS 开放猜想、一条 **15 年** 代数几何 Hilbert 函数问题，并改进凸优化 **Anchored GDA** 收敛界；单题推理成本约 **数百美元**。事后对比显示：最简「Ralph loop + Lean 反馈」基础 Agent 也能解同样 9 题，但在最难题（如 #125）上满配 Agent 成本效率 **2–5×** 更优——说明 **编译器接地** 与 **进化协调** 在最难实例上仍不可替代。

**关键观点**: AI 数学竞赛正分化为两轨——OpenAI 式**自然语言一次性推理** vs DeepMind 式**可机器验证的形式化搜索**；后者更适合日常研究工具化部署。

🔗 [结果仓库](https://github.com/google-deepmind/alphaproof-nexus-results)

### 3. Language Models Need Sleep：长上下文下的离线记忆巩固

> 来源: arXiv (CMU / UMD) | 2026-05

论文提出类生物 **「睡眠」巩固机制**：当上下文窗口满时，模型在**无外部输入**阶段对近期 context 做 **N 次离线递归前向**，更新 SSM 块中的 **fast weights**，再清空 KV cache；唤醒阶段保持**单次前向**低延迟预测。在 **Rule 110**（P-complete 元胞自动机 rollout）与 **Depo** 多跳图检索等合成任务上，纯 attention-SSM 混合体随推理深度增加而崩溃，而增加 sleep 时长 **N** 可显著恢复性能；在 **GSM-Infinite** 等更真实数学推理上亦有验证。核心论点：**可扩展记忆 ≠ 可扩展推理**——把被驱逐的 context 写入 fast weight 本身需要足够深度的离线计算。

**关键观点**: 长上下文军备竞赛的下一战场可能是 **「睡眠算力预算」**——在推理延迟不变前提下，用周期性离线巩固换取对已驱逐 token 的深度推理。

🔗 [论文](https://arxiv.org/abs/2605.26099)

> 来源: OpenAI | 2026-05-12 起

**Daybreak** 是 OpenAI 将前沿模型能力导入软件安全生命周期的倡议：结合 **OpenAI 模型**、**Codex 作为 Agent harness** 与安全生态伙伴，把安全代码审查、威胁建模、补丁验证、依赖风险分析、检测与修复指导嵌入日常开发环。访问分三档：**GPT-5.5（默认）**、**GPT-5.5 + Trusted Access for Cyber**（已验证防御工作流）、**GPT-5.5-Cyber**（受限预览，授权红队/渗透测试）。与 Anthropic **Mythos / Glasswing** 的「进攻型漏洞发现」形成对照——行业出现 **Daybreak（守） vs Mythos（攻）** 两条产品线。Cloudflare、Cisco、CrowdStrike、Palo Alto 等已参与；企业需通过官网 **Request a scan** 申请，Codex Security 仍为研究预览。

### 6. MeMo：Memory 与 Executive 分离的模块化知识注入

> 来源: arXiv (NUS / MIT CSAIL / SMART) | 2026-05

**MeMo（Memory as a Model）** 将新知识编码进独立的 **MEMORY 小模型**（如 Qwen2.5-14B），**EXECUTIVE 主模型**（如 Qwen2.5-32B 或 Gemini-3-Flash）保持冻结，仅通过标准 API 多轮查询 Memory。训练侧用 Generator 对语料做 **五步合成**（事实抽取 → 合并 → 自包含验证 → 实体浮现 → 跨文档合成）得到 **reflection QA**；推理侧 Executive 将复杂问题分解为对齐 reflection 接口的子查询。在 **BrowseComp-Plus**、**NarrativeQA**、**MuSiQue** 上显著优于 BM25/RAG/HippoRAG2；**无需** Executive 权重或 logits，支持**闭源 API**；推理检索成本与语料规模**解耦**（固定 Memory 参数量）。还支持 **model merging** 增量合并多个语料训练的 Memory。

**关键观点**: RAG 的下一形态可能是 **「可交换的小记忆模型」**——主推理模型升级时 Memory 不必重训。

🔗 [论文](https://arxiv.org/abs/2605.15156)

### 10. 形式化数学 vs 自然语言数学：双轨并进的「Erdős 时刻」

> 来源: 综合 OpenAI（05-20）与 DeepMind（05-21）| 2026-05

本周延续 **Erdős 问题** 的 AI 突破叙事，但路径截然不同：**OpenAI** 用专有推理模型 **否定** 经典几何猜想（单位距离问题，自然语言证明）；**AlphaProof Nexus** 用 **Lean 可检查证明** 批量解决 **9** 道开放 Erdős 题。Terence Tao 曾警告：AI 在 Erdős 全集上成功率仍约 **1–2%**，且集中在较易条目；DeepMind 的 **9/353** 与 Tao 的估计高度吻合。行业含义：论文审稿与 Mathlib 维护者将获得大量 **机器生成形式化证明**；数学家需同时学会审 **自然语言** 与 **Lean** 两类产出。

**关键观点**: 「AI 会做数学」正在分裂为 **「会猜（NL）」** 与 **「会证（Formal）」** 两个市场——工具链与人才技能将随之分化。

## 趋势总结

1. **自举式 post-training**（Self-Verified Distillation）与 **睡眠巩固**（Sleep）代表「不堆参数也能变强」的两条架构路线——前者在 wake 时省算力，后者在 sleep 时换算力。
2. **OpenAI Daybreak** 与 **Anthropic Mythos/Glasswing** 把 frontier 能力产品化为 **守/攻** 两套安全栈，企业采购将从「买模型 API」转向「买 Agent 安全飞轮」。
3. **Grok V9 + Cursor 数据** 揭示 coding 模型竞争已进入 **数据联盟** 阶段——算力合作之外，补训数据流向开始公开化。
4. **AlphaProof Nexus** 证明形式化 Agent 在开放研究问题上可达 **可批量复现、单题数百美元** 的成本结构，数学工作流将默认「Lean 优先」。
5. **Antigravity 2.0** 与 DeployCo / ADK 2.0 共同表明：**2026 下半年默认开发范式 = 多 Agent 编排**，IDE 补全退居幕后。
