### 3. HydraHead：head 级 FA/LA 混合注意力新架构

> 来源: arXiv | 2026-06

新论文 **HydraHead** 提出在 **head 维度**（而非 layer 维度）混合 Full Attention（FA）与 Linear Attention（LA）——基于可解释性分析发现 **同层内各 head 功能异质**。

**核心创新**  
| 机制 | 效果 |
|------|------|
| 可解释性驱动 head 选择 | 仅对 retrieval-critical heads 保留 FA，其余用 LA |
| Scale-normalized fusion | 调和 FA/LA 输出分布差异 |
| 三阶段 transfer pipeline | 参数复用 + 蒸馏，**15B tokens** 训练即见效 |

**性能**  
- 512K context NIAH：**+69%** vs baseline，逼近 Qwen3.5（原生 256K ctx）  
- 以 **7:1 LA:FA** 比例匹配 layer-wise 3:1 hybrid 的长上下文表现  
- 通用推理能力 **不降级**

**关键观点**: 长上下文架构优化正从 **layer-wise hybrid（Nemotron/MiniMax 路线）** 细化至 **head-wise hybrid**——为「稀疏 FA + 高效 LA」提供更精细的 Pareto 前沿。

🔗 [arXiv 论文](https://arxiv.org/html/2606.20097v1)

### 4. LED（Latent Exploration Decoding）：ICML 2026 推理模型探索性解码

> 来源: 人大高瓴 / 小米 MiLM Plus / ICML 2026 | 2026-06-21

**LED**（Latent Exploration Decoding）被 **ICML 2026** 接收——解决 RL 后训练 LRM 的 **exploration collapse**：提高采样温度不再提升 pass@k。

**机制**  
- 观察：post-training 后 **最后一层熵坍缩**，中间层仍保留丰富不确定性  
- LED 从中间层 hidden states 恢复 latent posterior，选 **最大熵 depth 配置** 作为探索候选  
- **零训练、零参数**；仅在 DeepThink 阶段切换探索/标准解码

**结果（5 模型 × 6 基准）**  
| 指标 | 提升 |
|------|------|
| pass@1 | **+0.61 pp** 平均 |
| pass@16 | **+1.03 pp** 平均 |
| GRPO rollout 训练 | 精度 41.99→43.10（测试时切回常规解码）；训练+测试均用 LED 达 **45.44** |
| GRPO 训练效率 | 生成长度 **-10%**，时间 4.87h→4.44h |

**关键观点**: LED 证明 **推理侧解码策略** 可反哺 **RL 训练侧探索**——与 HydraHead（架构）、LCLM（上下文）形成 **train-free inference hack** 新品类。

🔗 [arXiv 论文](https://arxiv.org/pdf/2602.01698)  
🔗 [GitHub 代码](https://github.com/AlbertTan404/LED)

### 5. LCLM：encoder-decoder 端到端上下文压缩

> 来源: NYU / Modal Labs / Princeton / arXiv | 2026-06-08

**Latent Context Language Models（LCLM）** 家族通过 encoder-decoder 架构将长 token 序列压缩为更短 latent embedding 序列——改善 KV cache 内存瓶颈。

**训练规模**  
- 架构搜索 + **350B+ tokens** 持续预训练  
- 0.6B encoder + 4B decoder，压缩比 **1:4 / 1:8 / 1:16**

**Pareto 改进**  
- 在 general-task 性能、压缩速度、峰值内存三维度 **同时优于** 现有 KV cache 压缩方案  
- 可作为 **long-horizon agent backbone**——agent 先 skim 压缩上下文，按需 expand 相关片段

**关键观点**: 长上下文竞争出现 **第三条路线**：除 sparse attention（MSA）和 hybrid architecture（HydraHead/Nemotron）外，**encoder-decoder 压缩** 为 agent 工作流提供 **按需解压** 范式。

🔗 [HuggingFace 论文页](https://huggingface.co/papers/2606.09659)  
🔗 [arXiv 论文](https://arxiv.org/html/2606.09659)
