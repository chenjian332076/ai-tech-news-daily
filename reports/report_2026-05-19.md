## AI 前沿动态

### 1. OpenAI 成立 Deployment Company，收购 Tomoro

> 来源: OpenAI | 2026-05-11

OpenAI 宣布成立 **OpenAI Deployment Company**（DeployCo），作为独立业务单元，由 OpenAI 控股，初始融资 **逾 40 亿美元**，由 TPG 领投，Advent、Bain Capital、Brookfield 等 19 家机构参与。核心模式是向客户派驻 **Forward Deployed Engineers（FDE）**，从诊断高价值场景、重设计工作流，到连接模型、数据、工具与内控，交付可度量的生产系统。同日宣布收购应用 AI 咨询公司 **Tomoro**（Tesco、Virgin Atlantic、Supercell 等客户），预计带来约 **150 名** FDE 与部署专家。OpenAI 称逾 **100 万** 企业已采用其产品，下一阶段竞争焦点从「试点」转向「规模化部署与运营变革」。

**关键观点**: 模型能力竞赛之后，**部署与变革管理** 正在成为 OpenAI 商业化的第二战场。

🔗 [阅读原文](https://openai.com/index/openai-launches-the-deployment-company/)

### 2. 2028：全球 AI 领导力的两种情景

> 来源: Anthropic Research | 2026-05-14

Anthropic 发布政策长文，将 **2028** 视为「变革性 AI」可能落地的时间窗口，并对比两种情景：**民主国家维持算力与模型领先**（需收紧芯片出口、打击蒸馏攻击、加速本国采纳） vs **威权政权借漏洞追平甚至反超**（AI 规范由专制国家塑造、自动化镇压规模化）。文章将竞争拆解为四条战线——**智能、国内采纳、全球分发、韧性**——并强调 **算力** 是当前最关键投入；指出中国实验室靠人才、管制漏洞与蒸馏仍接近前沿，但缺乏足够本土高端芯片。文中以 **Mythos Preview**（Glasswing 项目）为例，称 Mozilla 单月修复安全漏洞数达 2025 全年近 20 倍，印证能力加速期已至。

**关键观点**: 2026 年的政策选择可能决定 2028 年是由民主国家还是威权政权书写 AI 规则。

🔗 [阅读原文](https://www.anthropic.com/research/2028-ai-leadership)

### 3. ChatGPT 个人理财体验（Plaid 驱动）

> 来源: OpenAI | 2026-05-15

OpenAI 向美国 **ChatGPT Pro** 用户（Web / iOS）推出 **Finances** 预览：通过 **Plaid** 安全连接逾 **12,000** 家金融机构（Intuit 即将支持），在仪表盘查看投资组合、支出、订阅与待付款项，并以「Financial memories」保存目标、房贷等上下文。对话默认使用 **GPT‑5.5 Thinking**；OpenAI 称与 50+ 位金融专家共建内部基准，Thinking 得分 **79/100**，Pro 版 **82.5/100**。用户可随时断开账户（30 天内删除同步数据）或删除财务记忆；临时对话不会访问已连接账户。

**关键观点**: ChatGPT 正从「回答理财问题」迈向 **基于真实账户数据的推理与规划**，金融生态（如 Intuit）将嵌入闭环。

### 4. Anthropic 收购 Stainless（SDK / MCP 基础设施）

> 来源: Anthropic | 2026-05-18

Anthropic 宣布收购 **Stainless**——自 2022 年起为 Claude API 生成各语言官方 SDK 的团队，亦为 OpenAI、Google 等提供 SDK、CLI 与 **MCP Server** 自动生成（TypeScript、Python、Go、Java、Kotlin 等）。官方表述聚焦 **Agent 只能连接它能调用的系统**：收购后将 Stainless 能力内化，加速 Claude 连接数据与工具；创始人 Alex Rattray 称观察 Claude 生态后「合并是顺理成章的决定」。此前媒体报道交易估值超 **3 亿美元**。

**关键观点**: 前沿竞争正从「模型智商」外延至 **开发者接入层与 MCP 分发基础设施** 的控制权。

🔗 [阅读原文](https://www.anthropic.com/news/anthropic-acquires-stainless)

### 5. Cursor 发布 Composer 2.5

> 来源: Cursor | 2026-05-18

**Composer 2.5** 在 Composer 2（基于开源 **Kimi K2.5**）之上，通过扩大训练、更复杂 RL 环境与 **25×** 合成任务规模，提升长程任务续航、复杂指令遵循与协作体验。技术亮点包括：**定向文本反馈 RL**（在出错回合插入 hint，用 on-policy 蒸馏 KL 修正局部行为）、特征删除等 ** grounded 合成任务**，以及 MoE 上的 **分片 Muon + 双 mesh HSDP** 优化器工程。定价：标准 **$0.50/$2.50**（每百万 input/output tokens），Fast 默认档 **$3/$15**；首周双倍用量。Cursor 还披露与 **SpaceXAI** 在 Colossus 2 上训练更大模型的计划（10× 算力）。

**关键观点**: 编码 Agent 模型的竞争进入 **RL 工程 + 合成环境规模 + 行为校准** 的精细化阶段。

🔗 [阅读原文](https://cursor.com/blog/composer-2-5)

## AI 工程实践

### 6. Codex 登陆手机：随时随地协作长程任务

> 来源: OpenAI | 2026-05-14

OpenAI 在 **ChatGPT 移动应用** 中预览 **Codex 远程连接**：通过安全中继层，手机可同步笔记本、Mac mini 或远程环境中的 **实时线程状态**——审阅终端输出、diff、测试结果，批准命令、切换模型或插入新指令，而凭证与文件仍留在原机器。同步 GA 的还有 **Remote SSH**（接入企业托管开发环境）、**Hooks**（密钥扫描、校验、日志、记忆等仓库级定制），以及面向 Enterprise/Business 的 **程序化访问令牌**；符合条件的工作区还支持 **HIPAA** 场景下的本地 Codex 使用。Windows 手机连接即将支持。

**关键观点**: 长程 Agent 的瓶颈从「模型能不能做」转向 **人类能否在关键节点及时介入**——移动端是新的控制面。

🔗 [阅读原文](https://openai.com/index/work-with-codex-from-anywhere/)

### 7. OpenAI × Dell：Codex 进入混合与本地企业环境

> 来源: OpenAI | 2026-05-18

双方合作将 **Codex** 对接 **Dell AI Data Platform** 与 **Dell AI Factory**，使 Agent 在客户已有治理的数据、代码库、文档与业务系统旁运行，而非强制上云搬迁。OpenAI 披露 Codex 周活开发者超 **400 万**，用途已从代码审查、测试、事故响应扩展到跨工具的报告汇总、线索甄别、反馈路由等 **知识工作**。Dell CTO Ihab Tarazi 强调在 **premises** 部署 Agent 是规模化落地的务实路径。

**关键观点**: 企业 Codex 采纳的下一跳是 **数据驻留 + 混合基础设施**，与 DeployCo 的「进厂改造」形成产品—交付闭环。

### 8. 为 Windows 构建 Codex 安全沙箱

> 来源: OpenAI Engineering | 2026-05-13

OpenAI 详述为何未采用 AppContainer、Windows Sandbox 或 MIC 等现成方案，而是自研基于 **受限令牌、文件系统 ACL、专用沙箱用户** 的 Windows 原生 Agent 沙箱：在真实开发者工作区读写，默认无广域网络，进程树继承降权。目标是在避免「全盘放行」的同时，让 PowerShell 等本地工具链可被 Codex 安全调用；实现已 **开源** 发布。同日 Codex 桌面端正式支持 Windows。

**关键观点**: Agent 安全不能照搬容器 VM 思路——需在 **真实 checkout 上最小权限执行**，操作系统级沙箱成为新标配。

🔗 [阅读原文](https://openai.com/index/building-codex-windows-sandbox/)

### 9. TanStack npm 供应链攻击：OpenAI 响应与证书轮换

> 来源: OpenAI | 2026-05-13

OpenAI 披露 **Mini Shai-Hulud** 攻击污染 **TanStack npm** 后，两台员工企业设备受影响，恶意软件对有限内部代码库实施 **凭证导向外泄**；未发现用户数据、生产系统或 IP 被篡改。受影响仓库含 **iOS/macOS/Windows 签名证书**，公司将轮换证书并要求 **macOS 用户于 2026-06-12 前** 通过官方渠道更新 ChatGPT Desktop、Codex App 等（旧版 1.2026.125 等将失效）。OpenAI 称 Axios 事件后已加速 **minimumReleaseAge**、CI 凭证加固等控制，但此次两台设备尚未部署新包管理策略。

**关键观点**: 上游 npm 投毒可在数小时内波及签名链与 FDE 笔记本——**供应链 + 代码签名** 是 AI 公司的共同攻击面。

🔗 [阅读原文](https://openai.com/index/our-response-to-the-tanstack-npm-supply-chain-attack/)

### 10. LeCun 押注「世界模型」：LLM 非通用人智能之路

> 来源: 访谈 / NYU Tandon 2026 毕业季演讲等 | 2026-05 上旬

Yann LeCun 在 5 月多次公开表态：纯 LLM **无法** 通向人类级智能，因缺乏对物理世界的理解；其新创 **AMI Labs**（约 **10 亿美元** 融资）聚焦 **JEPA（Joint Embedding Predictive Architecture）**——非生成式、用嵌入向量预测行动后果的「世界模型」，以构建可靠 Agent。5 月 18 日他在 NYU Tandon 毕业典礼发表演讲，延续「AI 必须 grounded in the real world」的叙事，与主流 scaling LLM 路线形成鲜明对照。

**关键观点**: 2026 年的范式之争不仅是 OpenAI vs Anthropic，还包括 **生成式 LLM vs 世界模型** 两条技术哲学。

## 趋势总结

1. **「部署」成为与「训练」并列的护城河**：OpenAI DeployCo、Dell 本地 Codex、Anthropic×PwC 等动作表明，2026 年 H2 的竞争焦点是 **谁能把 Agent 嵌进客户真实工作流**，而非谁多发布一个 benchmark。

2. **Codex 从 IDE 插件进化为跨端操作系统级 Agent**：一周内的移动遥控、Windows 沙箱、企业混合部署，勾勒出「开发 + 知识工作 + 运维」统一 Agent 层的雏形。

3. **地缘 AI 叙事制度化**：Anthropic 将 2028 情景、算力管制与 Mythos 级能力绑在一起，预示 **政策与安全评估** 将更频繁地出现在前沿实验室的公开话语中。

4. **开发者基础设施并购升温**：Stainless 收购说明 **MCP/SDK 连接层** 已是战略资产；谁控制 Agent 触达 API 的方式，谁就控制生态分发。

5. **供应链攻击威胁签名与 FDE 笔记本**：TanStack 事件提醒：AI 公司既是软件消费者也是 **签名密钥持有者**，npm 投毒可在数日内迫使全球客户端强制更新。
