## AI 前沿动态

### 1. Sparse Feature Attention：特征轴稀疏化Attention的新维度

> 来源: arXiv / ICLR 2026 (Xie et al., Amazon AGI SF Lab & MIT) | 2026-03

论文 **Scaling Attention via Feature Sparsity** 提出 **Sparse Feature Attention (SFA)**——将 Q/K 向量转为 **top-k 稀疏码**，attention 成本从 Θ(n²d) 降至 Θ(n²k²/d)，约为 dense 的 **(k/d)²** 分数。配套 **FlashSFA** 内核扩展 FlashAttention，在稀疏 overlap 上直接计算、不物化 n×n score 矩阵，保持 exact softmax 语义。

在 GPT-2 与 Qwen3-0.6B 预训练上，SFA 匹配 dense perplexity，128K 上下文解码吞吐提升最高 **2.5×**，FLOPs 与 KV-cache 各降近 **50%**。NIAH 合成基准上，SFA 在 32K 训练、32K 测试时 accuracy **82%** vs dense 80%，且 **1.3×** 更快。论文强调 SFA 与 Longformer/NSA 等 **token 轴稀疏正交可组合**——理论上 d=1024、k=32 时可再降 **1000×** 交互成本，为「数量级更长上下文」打开新轴。

**关键观点**: 长上下文军备竞赛出现第三条路线——不是窗口/线性/RAG，而是 **保留全 token 覆盖、稀疏特征维度**；FlashSFA 使该路线可落地训练与推理。

🔗 [论文](https://arxiv.org/abs/2603.22300)  
🔗 [代码](https://github.com/YannX1e/Sparse-Feature-Attention)

### 2. MSA：端到端可训练的亿级 Token 内在记忆

> 来源: arXiv (Evermind / Shanda / PKU) | 2026-03

**Memory Sparse Attention (MSA)** 将长程记忆建模为 **可微稀疏 attention 架构**，通过 document-wise RoPE、Top-k 文档路由与 KV 压缩，在训练/推理均实现 **近线性复杂度**。核心指标：从 16K 扩展到 **100M token** 时性能衰减 **<9%**——对比 Qwen2.5-14B-1M、MemAgent 等在同等规模下的灾难性退化。

MSA 三阶段推理：**① 离线全局 memory encoding** → **② 在线 routing 组装 sparse context** → **③ 稀疏生成**；配合 **Memory Parallel** 可在 **2×A800** 上完成 1 亿 token 推理。另提出 **Memory Interleaving** 机制，支持跨分散 memory 片段的多跳推理。论文将现有记忆范式分为参数型/RAG/潜状态型，论证 MSA 同时满足 **lifetime 容量、高精度、主流架构兼容、端到端可训、无灾难性遗忘** 五项 desiderata。

**关键观点**: 「Digital Twin / 终身 Agent」的下一基础设施可能是 **解耦 memory 容量与 reasoning 窗口** 的 intrinsic sparse memory——而非单纯拉长 context 或外挂 RAG。

🔗 [论文](https://arxiv.org/abs/2603.23516)

### 3. RePlaid：连续扩散 LM 首次与离散 DLM 同量级 Scaling

> 来源: arXiv (NVIDIA / Cornell / MBZUAI) | 2026-05-19

**RePlaid** 将 likelihood-based 连续扩散 LM **Plaid** 的 transformer 架构对齐 MDLM/Duo 现代实践，在 SlimPajama 上完成 **首个连续 vs 离散 DLM 统一 scaling law 对比**。结果：RePlaid（含 self-conditioning）达到与 AR 相同 validation loss 需 **20×** compute（MDLM 14×、Duo 22×）；OpenWebText 上 PPL bound **22.1**——连续 DLM 新 SOTA，超越 MDLM（23.1）与原版 Plaid（24.4）。

理论贡献：ELBO 优化 **① 自然恢复线性 cross-entropy 噪声日程**（无需启发式 time reparameterization）；**② 正则化 embedding 几何**，可学习 token embedding 是 PPL 增益最大组件（冻结则 PPL 从 22.1 崩至 39.4）。采样侧，DDPM 在 T≥64 时 GenPPL 优于 Duo；DPM-Solver++(2M) 在低 NFE  regime 进一步加速。

**关键观点**: 「连续扩散不如离散可扩展」的叙事被数据推翻——差距从 Plaid 时代的 **64×** 缩至 **20×**，连续 latent 的 ODE 蒸馏与 structured editing 优势重新值得押注。

🔗 [论文](https://arxiv.org/pdf/2605.18530)

### 4. Cola DLM：字节 Seed 层次化潜空间扩散语言模型

> 来源: ByteDance Seed / arXiv | 2026-05-07

**Cola DLM（Continuous Latent Diffusion Language Model）** 采用三阶段层次分解：**Text VAE** 学习 text↔latent 映射 → **block-causal DiT** 在连续潜空间用 Flow Matching 建模全局语义先验 → **条件解码器** 生成 token。扩散过程做的是 **「潜先验运输」** 而非 token 级观测恢复，将 **全局语义组织** 与 **局部文本实现** 解耦。

2B 参数规模、8 基准、严格匹配自回归与 LLaDA 基线，scaling 曲线至约 **2000 EFLOPs** 显示健康增长；推理时 prefix 编码 → 分块 prior transport → KV-cache 条件解码。HuggingFace 已开源权重与 Transformers 兼容推理管线（`ByteDance-Seed/Cola-DLM`）。与 MIT **ELF**（05-20 已报）同属「杀死 token 级生成」路线，但 Cola 强调 **VAE 压缩 + 块因果 DiT**，工程落地更完整。

**关键观点**: 2026 年 5 月连续空间 LM 出现 **双轨并进**——RePlaid 证明 likelihood scaling，Cola DLM 证明 **「先规划潜语义、再解码」** 的非 AR 产品形态可开源复现。

🔗 [论文](https://arxiv.org/abs/2605.06548)  
🔗 [GitHub](https://github.com/ByteDance-Seed/Cola-DLM)  
🔗 [模型权重](https://huggingface.co/ByteDance-Seed/Cola-DLM)

### 6. ElectrolyteGPT + fLine：AI 生成完整电池电解液配方

> 来源: UChicago PME / JACS Au | 2026-05-30

Amanchukwu Lab 的 **ElectrolyteGPT** 从「挑选单一分子」升级为 **生成完整配方**——同时设定盐、溶剂、添加剂、浓度与混合比，在多目标约束下（离子电导率、氧化稳定性、库仑效率、粘度）平衡 trade-off。团队发明 **fLine** 线表示法（基于 SMILES 扩展），编码结构 + 溶剂比 + 盐浓度 + 温度等变量，使 AI 理解 **混合物整体** 而非孤立分子。

实验验证：AI 推荐的多款 novel 配方在锂金属电池中性能 **媲美 SOTA 电解液**。数据侧 curated 电解液专用语料，避免通用 GPT 生成「药物样分子」。fLine 可推广至任意化学混合物设计空间（估计电解液组合空间 ~10⁶⁰）。

**关键观点**: 材料发现 AI 正从 **「分子生成」** 跃迁到 **「配方生成」**——fLine 类混合表示法是跨领域（电池、催化剂、配方药）的关键基础设施。

### 7. EAGLE 3.1：推测解码长上下文鲁棒性翻倍

> 来源: EAGLE / vLLM / TorchSpec | 2026-05-26

**EAGLE 3.1** 针对 EAGLE 3 的 **attention drift**（推测深度增加时 drafter 注意力从 sink token 漂向自生成 token）引入两项架构修复：**FC 归一化** + **后归一化 hidden state 反馈**。长上下文任务接受长度较 EAGLE 3 最高 **2×**；对 chat template / system prompt OOD 更鲁棒。

基于 TorchSpec 训练、vLLM 部署的 **Kimi K2.6 EAGLE 3.1 草稿模型**（`lightseekorg/kimi-k2.6-eagle3.1-mla`）在 SPEED-Bench 上：并发 1 时单用户吞吐 **2.03×**，C=4/16 仍保持 **1.71×/1.66×**。已合并 vLLM main，随 **v0.22.0** 发布；向后兼容 EAGLE 3 checkpoint。

**关键观点**: 生产推理的下一瓶颈不是 draft 模型大小，而是 **跨模板/长上下文的 acceptance 稳定性**——EAGLE 3.1 把 speculative decoding 从 lab benchmark 推向真实 serving 环境。

🔗 [草稿模型](https://huggingface.co/lightseekorg/kimi-k2.6-eagle3.1-mla)
